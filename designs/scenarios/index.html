Onboarding scenarios

Each card below previews a different user state on the homepage. The source of truth is always home/homepage.html — these scenarios just patch the onboarding banner via ?scenario= URL param. No duplicate files.

Pre-account — no accounts connected

Empty state

No accounts connected — zero state dashboard

Brand-new user who hasn't created a Surmount account or linked any broker. Portfolio and Active strategies sections show empty state CTAs. No dividend card or verify banner in the sidebar.

+10 brokers supported

Investing account — onboarding states

Onboarding · Step 1

New user — verify identity

First-time user who has submitted their application and needs to verify their identity.
Onboarding · Step 1

Documents submitted — under review

User uploaded their identity documents and is waiting for the compliance team to review.
Onboarding · Step 2

Identity approved — make first deposit

Identity verified. Next step is adding funds to the investing account before trading.
Onboarding · Step 3

Funded — pick first strategy

Account funded. User needs to pick their first investment strategy to activate trading.
Onboarding · Complete

Fully onboarded — full dashboard

User has completed all onboarding steps. No banner shown, full dashboard experience.
Onboarding · Error

Application rejected — unable to approve

System was unable to approve the user's application. Dismissable rejection card with support contact info replaces the onboarding card.
How to add a new scenario: Open scenarios/scenarios.js and add a new entry to the SCENARIOS object, then add a card above linking to homepage.html?scenario=your-id. No other files need to change.
